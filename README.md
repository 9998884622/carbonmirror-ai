# CarbonMirror AI

## Problem Statement

Carbon footprints are difficult for individuals to understand and reduce.

## Solution

CarbonMirror AI provides:

- Carbon Footprint Calculator
- Sustainability Score
- AI Sustainability Coach
- Future Emission Prediction
- Eco Challenges
- Accessibility Features

---

## Tech Stack

Frontend:
- React
- TypeScript
- Vite
- TailwindCSS

Backend:
- Node.js
- Express
- MongoDB

AI:
- Gemini API

---

## Features

### Carbon Calculator

Track daily emissions from:

- Transport
- Electricity
- Water
- Waste
- Food

### AI Coach

Personalized sustainability guidance.

### Future Prediction

Estimate future environmental impact.

### Accessibility

Inclusive design for all users.

---

## Installation

Install everything from the repository root:

npm install

Build both projects:

npm run build

Run the frontend and backend together:

npm run dev

Run only one project:

npm run dev:client
npm run dev:server
